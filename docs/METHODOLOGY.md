# Evidence methodology
The unit of analysis is a **specific claim**, not the number of games in a company catalogue.

## Evidence statuses
- **Official disclosure:** a primary privacy statement describes a category of collection or potential use. It is not proof that every listed title performs that action.
- **Documented game feature:** a primary game source describes a named functionality; it is not necessarily financial profiling.
- **Context only:** ownership or platform relationship without direct game-specific telemetry evidence.
- **Unverified allegation:** a claim reported by someone, without independently verified implementation. This category is excluded from verified counts.

## Each record must include
The exact scope (platform, publisher, game), date checked, a stable primary link where possible, what is shown, what is not shown, and one safe validation step.

## Correction protocol
If a link changes, preserve historical context; use dated corrections. Never silently upgrade an allegation to a verified status. Every disputed interpretation should cite the precise primary statement and acknowledge ambiguity.

## Responsible research
Do not collect credentials, session tokens, bystander traffic or children's data. Do not bypass anti-cheat or authentication. Redact device identifiers and personal information from all public evidence. Never infer server-side processing or a player's mental state solely from encrypted packet timings.
